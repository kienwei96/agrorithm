# Agrorithm — Design System Preservation

## Reference
The existing Agrorithm site uses a specific design system that must be preserved exactly.

## Chosen Approach: Faithful Rebuild

This is a rebuild using the exact existing Agrorithm design system. No new visual direction is proposed.

### Design Movement
Agricultural-tech minimalism — clean, editorial layouts with a warm, organic palette that contrasts with the precision of technology.

### Core Principles
1. **Warm parchment backgrounds** with near-black forest text — organic, not sterile
2. **Monospace data labels** for technical credibility (Space Mono)
3. **Serif display headlines** for editorial authority (Fraunces)
4. **Generous whitespace** with asymmetric section layouts

### Color Philosophy
- Primary: `#16241C` (near-black forest) — authority, nature, depth
- Accent: `#3E6E4C` (moss green) — growth, technology, trust
- Background: `#F6F3EC` (warm parchment) — approachable, organic, premium
- Card dark: `#1A2E22` — for data panels and contrast sections

### Typography System
- Display: **Fraunces** (serif, variable) — headlines, section titles
- Body: **Source Sans 3** — readable paragraphs, descriptions
- Data/Labels: **Space Mono** — sensor readings, stats, technical labels

### Layout Paradigm
- Full-width sections with contained content (max-w ~1200px)
- Asymmetric hero (text left, live panel right)
- Card-based information architecture for specs and features
- Dark panels for data/technical content against warm backgrounds

### Signature Elements
1. Live climate data panel with green dot indicator
2. Numbered problem cards (01, 02, 03 pattern)
3. Monospace labels with uppercase tracking

### Interaction Philosophy
- Subtle, purposeful animations on scroll reveal
- Data panels that feel "alive" with updating values
- Smooth scroll navigation between sections

### Animation
- Fade-up on scroll for sections (staggered 80ms)
- Gentle pulse on the "powered by agentic AI" indicator
- Number counting animations for stats

### Brand Essence
AI-powered urban farming infrastructure for Malaysia — making precision agriculture accessible to operators, entrepreneurs, and institutions.

### Brand Voice
Headlines are confident and declarative. CTAs are direct and professional. Copy avoids hype — it explains with clarity.
- Example: "Great harvests don't happen by chance. We engineered certainty."
- Example: "One compact pod. The climate advantage of a farm."

### Wordmark & Logo
"agrorithm" in lowercase with the "ithm" portion in accent green — a subtle nod to algorithm.

### Signature Brand Color
`#3E6E4C` — Moss Green (ownable, natural, technological)

## Style Decisions

- Partner/trust sections must never use placeholder labels; credibility is expressed through specific deployment categories, pilot statuses, or anonymized operator/institution types.
- Iconography follows a restrained agritech schematic style: mono labels, numbered systems, thin-line SVG sensors, pod diagrams, and moss-green signal accents — no emoji-like decorative icons.
- Imagery prioritizes Agrorithm's ownable world: Malaysian urban rooftops, compact controlled-environment pods, grow interiors, climate sensors, and operator-facing infrastructure.
